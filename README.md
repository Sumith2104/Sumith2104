## 🏆 Flagship Project: Fluxbase ⚡

> **Fluxbase** is a proprietary, next-generation **Serverless Database-as-a-Service (DBaaS)** built for fast-moving startups. It bridges the gap between predictable relational queries and infinite NoSQL scale.

💡 **Architectural Highlights:**  
- ⚡ **Serverless SQL-to-NoSQL Engine** – Features a custom Node.js AST (Abstract Syntax Tree) parser that translates complex standard SQL queries directly into optimized Google Firestore document operations in real-time.
- 🔐 **Edge-Ready Security** – Scoped, granular API keys authenticated at the edge, allowing zero-config safe external embedding for client applications.
- 📊 **Real-Time Telemetry** – Built-in Vercel-style analytics pipeline to monitor query distribution and latency instantly.
- 🎨 **Premium IDE Experience** – A stunning, dark-mode first Table Editor and raw SQL interactive scratchpad featuring split resizable panels and history tracking.

**Tech Stack:** Next.js 15, React, Node.js AST Parser, Google Cloud Firestore, Tailwind CSS, Radix UI
